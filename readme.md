# JavaScript Shopping Cart
A beginner-friendly shopping cart project built using HTMl,CSS and JavaScript

## Features
- Add products to cart
- Remove products from cart
- Dynamic cart Rendering
- Automatic cart count update
- Automatic total price calculation
- Scrollable cart section

## Technologies Used
- HTML5
- CSS3
- JavaScript(DOM Manipulation, Arrays, Objects, Events)

## What I learned
- DOM Manipulation
- Event Delegation
- Array methods: forEach(), filter(), reduce(), Map().
- Dataset and closest()
- Dynamic element creation
